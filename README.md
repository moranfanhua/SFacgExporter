# SFacgExporter 菠萝包轻小说导出工具

## 使用方法
输入账号密码登录，在网页端获取小说ID，点击读取目录后勾选想要导出的卷与章节，选择想要导出的格式和位置，点击导出所选卷。

## 开源库

- 桌面 UI 框架及主题：[Avalonia](https://github.com/AvaloniaUI/Avalonia)
- 2D 图形渲染库：[Skia](https://github.com/google/skia) & [SkiaSharp](https://github.com/mono/SkiaSharp)
- 字体排版库：[HarfBuzz](https://github.com/harfbuzz/harfbuzz) & [HarfBuzzSharp](https://github.com/mono/SkiaSharp)
- 图形接口转换库：[ANGLE](https://github.com/AvaloniaUI/angle)
- COM 互操作库：[MicroCom](https://github.com/kekekeks/MicroCom)
- C# JSON 库：[System.Text.Json](https://github.com/dotnet/runtime)
- C# 数据流库：[System.IO.Pipelines](https://github.com/dotnet/runtime)
- 电子书验证库：[System.IO.Compression](https://github.com/dotnet/runtime) & [System.Xml.Linq](https://github.com/dotnet/runtime)
- C++ 标准库：[MSVC STL](https://github.com/microsoft/STL)
