# SFacgExporter 菠萝包轻小说导出工具

## 使用方法
输入账号密码登录，在网页端获取小说ID，点击读取目录后勾选想要导出的卷与章节，选择想要导出的格式和位置，点击导出所选卷。

支持 Windows x64 和 Android arm64（Android 6.0 及以上）。Android 通过系统选择器授权保存目录，导出时请保持应用在前台。
